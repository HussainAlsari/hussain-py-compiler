Get started with Hussain Compiler

Go from a blank editor to a running Python program in about a minute. Nothing to install, nothing to sign up for.

Run your first program

  1. Open the editorGo to hussaincompiler.com. A file called main.py is already waiting for you in the Explorer on the left.
  2. Write a few linesClick inside the editor and type: 
    name = input("What is your name? ")
print("Hello,", name)
  3. Press Run PythonUse the blue button at the top right of the editor, or press Ctrl + Enter. The first run takes a little longer while the Python runtime downloads.
  4. Answer in the terminalThe question appears in the terminal at the bottom. Click there, type your name, and press Enter to see the result.
  5. Save your workPress Ctrl + S to keep the file in this browser, or use Download to save a copy to your computer.

Useful things to try next

Add more files

Create extra .py files in the Explorer, then use import to load one from another.

Install a package

Type a package name in the Python Packages box and press Install. It uses micropip, so pure-Python packages work best.

Follow a lesson

Open the courses from the activity bar. Each lesson loads starter code and checks your requirements as you type.

Share a result

Use Save PNG in the terminal header to export your code and its output as one image.

Change the language

Open Settings, then Editor Settings, to switch the interface or the lessons between English and Arabic.

Fix errors quickly

When Python reports a problem, the message names the file and the line number so you can jump straight to it.

Good to know

Hussain Compiler runs Python in WebAssembly, so packages that rely on native system code may not load. Your files live in your own browser; clearing browser data removes them, so download anything important. The project is open source and maintained by Hussain on GitHub.
