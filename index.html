A practical guide for new programmers

Learn Python by understanding what your code does

Python is a readable programming language used for automation, data work, websites, and learning computer science. This guide explains the building blocks with small examples, describes common mistakes, and gives you practice tasks. You can run the examples in the free browser editor, but you can also follow the lessons with any Python 3 installation.

Start with output, values, and variables

A program is a set of instructions. print() displays a value so you can see what the program calculated. A variable gives a value a name, which makes it easier to reuse and update.

name = "Maya"
age = 14
print("Hello", name)
print("Next year you will be", age + 1)

Here, name stores text (a string) and age stores a whole number (an integer). Python chooses the type from the value you assign. To combine text and a number, convert the number with str(age), or use an f-string such as f"Age: {age}".

Common mistake: age = "14" is text, not a number. Adding 1 to it raises a type error. Convert user input with int() before doing arithmetic.

Make decisions with conditions

An if statement runs a block only when its condition is true. Use elif for another possibility and else for the remaining case. Indentation marks which lines belong to each branch.

score = 72
if score >= 90:
    print("Excellent")
elif score >= 50:
    print("Passed")
else:
    print("Try again")

Comparisons such as ==, !=, <, and >= produce true or false. A frequent beginner error is writing = where a comparison is needed: one equals sign assigns a value; two compare values. Conditions can be combined with and and or.

Practice: Set a temperature variable. Print “cold” below 15, “warm” from 15 through 27, and “hot” above 27. Test the boundary values 14, 15, 27, and 28.

Repeat work with loops

A for loop visits each item in a sequence. range(start, stop) includes the start but stops before the stop value, which is why range(1, 6) produces 1 through 5.

total = 0
for number in range(1, 6):
    total = total + number
print(total)  # 15

The loop updates total once per turn. This accumulator pattern is useful for sums and counts. A while loop repeats while a condition remains true; make sure something inside the loop eventually changes that condition, or it may never stop.

Practice: Print the multiples of 3 from 3 to 30. Then change the program to add them together. Check your result by calculating a few terms by hand.

Use lists and functions to organize code

A list stores an ordered collection. Its index begins at zero, and append() adds an item to the end. Functions package a task behind a name so you can call it more than once.

def average(numbers):
    if len(numbers) == 0:
        return 0
    return sum(numbers) / len(numbers)

scores = [80, 95, 70]
scores.append(85)
print(average(scores))

The function returns a value instead of printing it, so another part of the program can reuse the result. Handling an empty list also prevents division by zero. Small functions make it easier to read and debug one piece at a time.

Practice: Write a function that accepts a list of prices and returns the largest price. Try it with an empty list, one value, and several values. Decide what result makes sense for the empty case.

Debugging: read the first useful error

When a program fails, read the last lines of the traceback first. Python usually names the error type and points to the line where it noticed the problem. The original cause may be a few lines earlier. Check spelling, quotes, parentheses, indentation, and the type of each value.

  • SyntaxError: Python could not parse the instruction, often because punctuation or indentation is missing.
  • NameError: a name was used before it was defined, or its spelling differs.
  • TypeError: an operation does not work for those value types.
  • IndexError: a list index is outside the available positions.

Change one thing at a time, run the program again, and compare actual output to expected output. Add temporary print() calls to inspect intermediate values, then remove them when the issue is solved.
